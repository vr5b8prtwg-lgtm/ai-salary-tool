# AI 标注员工薪酬结算工具

本地网页工具：导入标注统计 Excel（.xls / .xlsx），自动按“员工 × 项目 × 月份”统计标注题数，设置项目单价后生成薪酬结算表，支持导出 Excel / CSV。

## 如何启动
1. 双击 `启动工具.bat`（或安装依赖后运行 `python app.py`）。
2. 浏览器打开 `http://127.0.0.1:5000`。
3. 按页面三个步骤操作：① 上传并统计 → ② 设置单价 → ③ 税前薪酬。

## 统计规则
- 员工按“标注员”归集（为空时用“账户名”）。
- 仅昵称（账户名）空白的行，按该行标注员归属，并在页面提示中汇总说明。
- 异常数据按月排布：隐藏整行全空的空行，按归属月份筛选/排序，日期被修正过的会显示“原日期 → 修正后日期”并按修正后日期归月份。
- 列外补充说明：表头为空的列里的补充内容（如员工在锁表后写“22（前面数据登记错了）”）会被识别并列入异常数据供人工核算；被跳过的行如果也有补充内容，同样会附在跳过说明里。
- 日期笔误识别：月日粘连（如 2027/727 按 2027/7/27）会自动解析；数据年份超出当前年份时（如 2027、3027年），自动把年份改为当前年份（仅调整年份，月日不变）并提示；无法识别的日期归入“未标注日期”并提示。
- 项目按“任务ID”识别，任务ID为空时用“任务名称”（如“模型对战”表）。
- 数量口径：`Dpo arena 评测`用“实际题数”；`dcc年龄 / html评测 / 模型对战`的“产值”即题数；`动态IP标志性动作采集 / 特殊运镜采集`按“备注”中“X题”换算（题数 = 产值 × X）。
- 空行、无员工、无项目、数量无效的行会跳过并在页面提示。
- 单价以“元/题”为单位，保存在同目录 `prices.json`，重启后保留；按大类（工作表）统一单价，设一个大类即应用到该大类全部项目，并提供常用默认单价（可修改）。
- 税前薪酬（第④步）：每位员工应发税前薪酬 = 各项目（完成数×单价）合计 + 异常表单统计金额（手工填入，保存在 `abnormal_amounts.json`），并统计总员工应发税前薪酬，可导出 CSV。
- 工作量统计：全周期汇总每个员工×每个项目的题数、原始产值、记录数、完成天数，可导出。
- 工作量筛选：支持按月份、员工、项目、题数区间筛选每位员工/项目的题数、原始产值、记录数、完成天数；并直接展示被跳过/带提示的异常行（含员工、项目、数量）供人工核算，可导出筛选结果 CSV。
- 工作量筛选：可按员工、项目、题数区间筛选工作量（项目使用完整名称）；并直接展示被跳过/带提示的异常行（含员工、项目、数量）供人工核算，可导出筛选结果 CSV。

## 文件说明
- `app.py`：网页后端与导出
- `parser.py`：Excel 解析与统计逻辑
- `templates/index.html`：页面
- `tests/test_parser.py`：自动校验脚本（可重复运行）
